# Course Overview

Hello, and welcome to the **Agentic AI with LangChain and LangGraph** course.

You will begin by learning how to design agentic workflows using LangGraph, with a focus on memory, iteration, and conditional logic. Through interactive lessons and hands-on labs, you will explore how LangGraph builds on LangChain to enable adaptive decision-making using nodes, edges, and shared state.

As you progress, you will apply these skills to build self-improving agents using architectures such as **Reflection**, **Reflexion**, and **ReAct**. You will also learn how to coordinate specialized agents within multi-agent systems, including agentic retrieval-augmented generation (RAG) pipelines that route queries to relevant data sources. Each concept is reinforced through practical labs designed to help you confidently implement advanced agentic AI systems.

This course is part of the **IBM RAG and Agentic AI Professional Certificate**, which is designed to equip you with the practical skills and knowledge needed to develop advanced AI applications leveraging RAG, multimodal AI, and agentic systems.

# Objectives

By the end of this course, you will be able to:

- Build agentic AI systems using LangChain and LangGraph to support memory, iteration, and conditional logic
- Design and implement self-improving agents using Reflection, Reflexion, and ReAct architectures
- Apply agent orchestration techniques to create collaborative multi-agent systems
- Implement agentic RAG systems that support query routing and retrieval-enhanced reasoning
